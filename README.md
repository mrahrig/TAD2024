# Text As Data Sentiment Prediction
- Included is R file for analyzing text data pulled as csvs from Reddit posts
- LDA is used to identify common text trends
- Corpus is used to identify positive or negative sentiment
- A sample of posts is used as training data, being labeled by theme and inserted into Naive Bayes and SVM machine learning models to create a model that can accurately predict the themes of other posts based on text
- Confusion matrix is used to validate the models and identify the better fit
